## Optimizing Docker Builds with Layer Caching

### 1. How Docker Build Caching Works

When you rebuild a Docker image, Docker doesn’t blindly redo everything. It checks each instruction and reuses previously built layers if nothing has changed.

- Each Dockerfile line = **a layer**
- Docker compares:
  - current instruction
  - files involved in that step
- If unchanged → **uses cached layer**
- If changed → **rebuilds from that step onward**

Important rule:

*Once one layer changes, **all layers after it must rebuild***

### 2. What Happens When You Change Your Code

Let’s say you only modify `index.js` and rebuild.

Docker sees:

- `FROM`, `USER`, `RUN mkdir`, `WORKDIR` → unchanged ✅ (cached)
- `COPY . .` → changed ❌ (because files changed)

So Docker:
- Reuses earlier layers
- Starts rebuilding from COPY
- Re-runs everything after it

### 3. The Real Problem: Slow Steps

Some steps are much slower than others—especially ones that use the network.

Biggest culprit:

```dockerfile
RUN npm ci
```

Why it’s slow:

- Downloads dependencies from internet
- Can take several seconds or minutes

Problem:
- Even if only `index.js` changes
- Docker still reruns `npm ci` (because it comes after `COPY`)

### 4. Optimization Idea

You want `npm ci` to run only when dependencies change, not when app code changes.

Dependencies are defined in:
- `package.json`
- `package-lock.json`

So:
- Separate dependency files from app code in build steps

### 5. Solution: Split COPY into Two Steps

Optimized Dockerfile:

```dockerfile
FROM node:20

USER node

RUN mkdir /home/node/code

WORKDIR /home/node/code

COPY --chown=node:node package-lock.json package.json ./

RUN npm ci

COPY --chown=node:node . .

CMD ["node", "index.js"]
```

**Step 1: Copy only dependency files**

```dockerfile
COPY package-lock.json package.json ./
```
- Only changes when dependencies change
- Triggers `npm ci` only when needed

**Step 2: Install dependencies**

```dockerfile
RUN npm ci
```
- Cached if package files didn’t change
- Skipped on rebuild if unchanged

**Step 3: Copy the rest of the app**

```dockerfile
COPY . .
```
- Includes `index.js` and other files
- Changes frequently
- But **does NOT trigger `npm ci` again**
