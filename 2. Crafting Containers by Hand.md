## 2. chroot

`chroot` (change root) is a command to choose the root folder of your shell.

`docker ps` — show running Docker images/processes.

</br>

### Creating custom Docker

`docker run -it --name docker-host --rm --privileged ubuntu:jammy`

- `docker run` — run the image
- `-it` — interactive mode
- `--name` — name of the Docker image
- `--rm` — removes / deletes everything after exiting or killing the container
- `--privileged` — gives root privileged
- `ubuntu:jammy` — Ubuntu image, Jammy

</br>

### Inside `ubuntu:jammy`

`root@0fb4cb65e1f9:/#`

- `cat /etc/issue` — running OS / image version
- `mkdir my-new-root` — creates my custom root directory
- `echo "My secret key" >> /my-new-root/secrete.txt` — create `secrete.txt` and save the string in it

- `chroot /my-new-root/ bash` — change root to that directory, `bash` as interpreter; fails because `bash` is not there yet. Copy it in.

- `which bash` — where `bash` runs from (`/bin/bash` or `/usr/bin/bash`)
- `ldd usr/bin/bash` — libraries / dependencies for `bash` (e.g. `lib` and `lib64`)

- `mkdir /my-new-root/lib`
- `mkdir /my-new-root/lib64`
- `cp /lib/x86_64-linux-gnu/libtinfo.so.6 /lib/x86_64-linux-gnu/libc.so.6 /my-new-root/lib` — copy `bash` libs into `new-root` `lib`
- `cp /lib64/ld-linux-x86-64.so.2 /my-new-root/lib64/` — copy `bash` `lib64` into `new-root` `lib64`

- `mkdir /my-new-root/bin` — `bin` for executables
- `cp /usr/bin/bash my-new-root/bin/` — copy the `bash` binary into `new-root` `bin`

- `chroot my-new-root/ bash` — change root / shell to `new-root` with `bash` as interpreter (this time it works)

**Note:** Each time you want to run a command that is not available by default, copy its libs and `bin` into the directory.
