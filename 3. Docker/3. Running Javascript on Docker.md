## 3. Running Javascript on Docker
“How to run programming languages inside Docker containers”

### 1. Big idea first

A Docker image like:
- `node:20`
- `python:3.12`
- `golang:1.22`

Is a ready-made computer with that language already installed

So instead of installing Node.js on your laptop, you just run a container that already has it.

### 2. Node.js container (normal run)
```sh
docker run -it node:20
```

**What happens:**
- Docker downloads Node.js environment
- Starts container
- Drops you into: ***`Node REPL` (JavaScript terminal)***

You can type JavaScript directly:
```log
console.log("hello")
```

### 3. Check Linux inside container
```sh
docker run -it node:20 cat /etc/issue
```

**What happens:**
- Instead of Node.js, you run a command
- It prints the Linux system inside
- Answer: Debian Linux

Key idea: ***Containers are just Linux systems with tools installed***

So Node image = Debian Linux + Node.js already installed

### 4. Get bash instead of Node

```sh
docker run -it node:20 bash
```

**What happens:**
- Normally Node container opens Node.js
- But now you override it
- You get a Linux terminal instead

You are inside the container like a normal Linux machine

⚡ Important concept
```sh
docker run node:20 <command>
```
Anything after the image = what you want to run instead of default

### 5. Lightweight version (Alpine)

```sh
docker run -it node:20-alpine cat /etc/issue
```
**What it means:**
- Same Node.js
- But smaller Linux system (Alpine)
- faster, lighter containers

### 6. Other runtimes (same idea)

These all work the same way:

```sh
docker run -it python:3.12
docker run -it golang:1.22
docker run -it ruby:3.3
docker run -it php:8.2
```
**What happens:**
- Each one gives you a ready-made environment
- No installation needed
