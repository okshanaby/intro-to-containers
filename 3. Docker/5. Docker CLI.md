Let's take a look at some more cool features of the Docker CLI.

### 1. `pull` allows you to pre-fetch container to run.
It downloads a container image from Docker Hub and stores it in the local cache, without running the container

```sh
# this just downloads and caches the image, it doesn't do anything else with it
docker pull bcbcarl/hollywood

# notice it's already loaded and cached here; it doesn't redownload it
docker run -it bcbcarl/hollywood
```

That will pull the hollywood container from the user bcbcarl's user account. The second line will execute this fun container which is just meant to look a hacker's screen in a movie (it doesn't really do anything than look cool.)

### 2. `push` allows you to upload your image to Docker Hub (or other registry)

```sh
docker push <image>
```
This allows you to push containers to whatever registry you're connected to (probably normally Docker Hub or something like Azure Container Registry or GitHub Container Registry).

### 3. `inspect` (deep details)

```sh
docker inspect node:20
```
This will dump out a lot of info about the container. Helpful when figuring out what's going on with a container

### 4. `pause` / `unpause` - Pause a running app without stopping it

As it looks, these pauses or unpause all the processes in a container. Feel free to try

```sh
docker run -dit --name hw --rm jturpin/hollywood hollywood
docker ps # see container running
docker pause hw
docker ps # see container paused
docker unpause hw
docker ps # see container running again
docker kill hw # see container is gone
```

### 5. `import` / `export` - Backup / restore container

```sh
#Save container → file
docker export container > file.tar

#Load it back later
docker import file.tar
```

### 6. `history` - Shows how the image was built (layers)

This allow you to see how this Docker image's layer composition has changed over time and how recently.

```sh
docker history node:20
```

### 7. `info` - Shows system-wide Docker info

Dumps a bunch of info about the host system. Useful if you're on a VM somewhere and not sure what the environment is.

```sh
docker info
```

### 8. `top` - Shows running processes inside container

Dumps a bunch of info about the host system. Useful if you're on a VM somewhere and not sure what the environment is.

```sh
docker run -dit --name my-mongo --rm mongo
docker top my-mongo # you should see MongoDB running
docker kill my-mongo
```

### 9. `logs` - See what the app is printing

Very useful to see the output of one of your running containers.

```sh
docker run --name my-mongo --rm -dit mongo
docker logs my-mongo # see all the logs
docker kill my-mongo
```

### 10. `restart` - Stop + start again

```sh
docker restart <container>
```


### 11. `search` - Find images online

If you want to see if a container exists on Docker Hub (or whatever registry you're connected to), this will allow you to take a look.

```sh
# see all the various flavors of Python containers you can run
docker search python 

# see all the various flavors of Node.js containers you can run
docker search node 
```
