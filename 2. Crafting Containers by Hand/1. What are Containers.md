## 1. What are Containers

`Containers` are lightweight, isolated environments that run your application with everything it needs.<br>

Its like a lightweight isolated running operating system serving process, application and minimal file system. It runs in a host machine

While Container `Image` is basically a packaged blueprint of a container’s filesystem + instructions on how to run it 

Think of a container like this:

```sh
HOST MACHINE (your Linux system)
│
├── Docker Engine (normally manages everything)
│
└── Container (isolated mini-system)
    ├── Filesystem (Ubuntu/Alpine root)
    ├── Processes (sh, node, etc.)
    ├── Network namespace
    └── Resource limits (cgroups)
```
