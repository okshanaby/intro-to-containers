## The actual task

You must create a multi-stage Dockerfile that:

### Stage 1 (Builder)
- Uses Node.js
- Installs dependencies
- Builds the app

### Stage 2 (Runtime)
- Uses NGINX
- Serves the built files

### Important constraint

You must:

- Copy only the built output
- Not the entire project
- Specifically: `/dist → /usr/share/nginx/html`

Why:

- NGINX serves static files from that directory by default
- It already knows how to serve them correctly

### What NGINX is doing here

NGINX is:

- A static file server
- Handles HTTP requests
- Serves your built frontend

Important detail:

- You don’t need to write a start command
- The container already has a default CMD that starts NGINX

### The solution Dockerfile

```dockerfile
FROM node:20 AS node-builder
WORKDIR /app
COPY . .
RUN npm ci
RUN npm run build

FROM nginx:latest
COPY --from=node-builder /app/dist /usr/share/nginx/html
```

### What you run

```sh
docker build -t my-static-app .
docker run -it -p 8080:80 --name my-app --rm --init my-static-app
```
