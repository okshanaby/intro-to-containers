## Making our own Node.js Alpine container

We are building our own lightweight Node.js Docker container using Alpine Linux instead of using the official Node image.

Why do this:

- Smaller image size (faster downloads, less storage)
- Better understanding of how containers work

### Step 1: Base Image

```dockerfile
FROM alpine:3.19
```

- This is a minimal Linux system
- Very small compared to other base images

### Step 2: Install Node.js and npm

```dockerfile
RUN apk add --update nodejs npm
```

- `apk` is Alpine’s package manager
- Installs Node.js and npm

If you get an error about syntax (older Node version), use:

```dockerfile
RUN apk add --update nodejs-current npm
```

**Important Note About Alpine**
- Alpine does not use bash
- It uses `sh` (a simpler shell)

### Step 3: Create a Non-Root User

```dockerfile
RUN addgroup -S node && adduser -S node -G node
USER node
```

- Creates a user called node
- Runs the container as that user instead of root
- This improves security

### 4. Final Dockerfile (Optimized + Small)

```dockerfile
FROM alpine

RUN apk add --update nodejs npm

RUN addgroup -S node && adduser -S node -G node

USER node

RUN mkdir /home/node/code

WORKDIR /home/node/code

COPY --chown=node:node package*.json ./

RUN npm ci

COPY --chown=node:node . .

CMD ["node", "index.js"] 
```
